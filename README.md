# manhhai.github.io

Đồng hồ phụ cho BMW 320i F30, dùng với adapter vLinker BM+ qua Web Bluetooth (Chrome trên Android, hoặc app Bluefy trên iPhone).

`index.html` gồm:
- Tốc độ thực cỡ lớn, chọn giới hạn 50–120 km/h, đổi màu và bíp khi vượt tốc.
- Cảnh báo, nhiệt độ nước làm mát và dầu máy, vòng tua, khí nạp, điện áp ắc quy.
- Áp suất lốp, nhắc thay dầu, ngưỡng cảnh báo và công cụ dò mã.
