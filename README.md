# manhhai.github.io

Các trang đồng hồ OBD cho BMW 320i F30, dùng với adapter vLinker BM+ qua Web Bluetooth (Chrome trên Android, hoặc app Bluefy trên iPhone).

- `index.html` — Đồng hồ phụ F30: nhiệt độ, cảnh báo, áp suất lốp, dò mã.
- `toc-do/` — Đồng hồ tốc độ: tốc độ thực cỡ lớn, chọn giới hạn, cảnh báo và bíp khi vượt tốc.
